Your questions

DataDoes my data leave my PC?

No. Tally reads the files your agents already write to your disk, and keeps its totals in a small SQLite database in %APPDATA%\Tally. The only network request is a check for new versions on GitHub.

AgentsWhich agents are supported?

Claude Code, Codex, OpenCode, Kimi Code, Grok CLI and Cursor. Each agent is a small Rust module: the ADD_A_PROVIDER.md guide shows how to add one.

macOSDoes it work on macOS or Linux?

Not yet. Tally is built with Tauri, so a port is possible, but for now it targets Windows 10 and 11 and their system tray.

AccuracyAre the numbers right?

Tally counts each message once, even when an agent writes it several times in its logs. Its totals stay within 1% of ccusage on the same files.

CacheWhy are my numbers so big?

Because cache counts. An agent rereads its whole context on every message, and those reads add up to millions. Turn off “Count cache” in settings to see only input and output.

ResourcesDoes it slow down my PC?

No. After a first pass, Tally only reads what was added since last time. At rest, it just waits for a file to change.

PriceHow much does it cost?

Nothing. Tally is free and MIT licensed. No paid tier, no account, no limit.
